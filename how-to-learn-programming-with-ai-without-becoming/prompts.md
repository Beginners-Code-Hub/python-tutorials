# 3 prompts for learning with AI

1. **Explain** - "Explain this error in simple words. Don't give me the fixed code."
2. **Hint** - "Give me a hint, not the answer. One line at a time."
3. **Review** - "Review my code and tell me ONE thing to improve."

Never as a beginner: "Write the whole project for me."
Better: "Give me the steps. I'll write each one and you check it."
